# Rezlee Home product model

Home is an operating brief, not a feature directory.

It answers four questions in order:
1. What needs me now?
2. What is changing?
3. What is coming?
4. How can Rezlee become more useful?

## Home Pulse
A transparent state derived from real household data, never an opaque score.
States: needs attention, steady, getting started.
Show a concise headline, one supporting sentence, and the number of open actions.
## Needs attention
Use a single prioritized list across Bills, Care, Vault, providers and issues.
Show at most three rows on Home; deeper detail belongs in each domain.
Urgency is communicated with icon, label and date/context, not card size.

## Home costs
Show known cost this month, paid vs remaining, previous-month comparison,
and a compact six-month trend. Charts must communicate a message, not decorate.

## Next 30 days
Combine upcoming bills, care tasks and document renewals into one timeline.
This is a preview, not a second full task list.
